# Athlete Connect · Starter

Dieser Ordner ist dein neutraler Startpunkt. Er zeigt bereits eine responsive Profilseite und ein HTML-Formular, enthält aber bewusst noch keine Datenbank, serverseitige Validierung oder fertige Tests.

## Starten

```bash
php -S localhost:8080 -t public
```

Öffne danach <http://localhost:8080>.

## Deine ersten Änderungen

1. Ersetze das Demo-Profil in `templates/home.php`.
2. Formuliere in `docs/briefing.md` deine User Story und fünf Akzeptanzkriterien.
3. Passe Felder und Gestaltung an deine Zielgruppe an.
4. Committe diesen Stand, bevor du die serverseitige Verarbeitung beginnst.

## Bewusst noch nicht vorhanden

- SQLite-Datenbank
- serverseitige Validierung
- CSRF-Schutz
- Repository-Klasse
- automatisierte Tests

Diese Teile entstehen in den Etappen 3 bis 6.
